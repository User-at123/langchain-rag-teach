# 星辰科技公司介绍

## 公司概况

星辰科技公司成立于2015年，总部位于深圳，是一家专注于人工智能产品的科技公司。公司愿景是"让每个企业都拥有自己的AI大脑"。

## 主营业务

星辰科技主营三大业务：

1. 智能客服系统
2. 知识库问答平台
3. 大数据分析服务

旗舰产品"星辰问答"已服务超过500家企业客户，覆盖金融、零售、教育等行业。

## 团队与融资

公司团队规模约200人，其中研发人员占比70%。2023年，星辰科技获得B轮融资1.5亿元，投资方包括星河资本和东方创投。

## 服务能力

客服系统支持中英文双语，平均响应时间小于1秒。公司在北京、上海设有分公司，并在新加坡设立了海外办事处。
